# Minesweeper AI v1.0

AI-бот для автоматической игры в Сапёр (Minesweeper) в браузере.

## Возможности

- 📸 Захват экрана и вырезание области игры
- 🔍 Распознавание клеток: цифры 1-8, мины, флаги, закрытые
- 🧠 Логический решатель с 3 правилами + вероятностный анализ
- 🖱️ Автоматические клики (левый — открыть, правый — флаг)
- 🛡️ Система безопасности: остановка при взрыве, ESC — аварийная остановка
- 🎯 Автоматический первый ход в центр

## Управление

| Клавиша | Действие |
|---------|----------|
| ESC | Аварийная остановка |

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

При первом запуске бот попросит выбрать область игры:
1. Появится скриншот экрана
2. Кликните по двум углам поля Сапёра
3. Нажмите ENTER

## Архитектура

```
main.py              → Точка входа
ai_controller.py     → Главный цикл: захват → распознавание → решение → клик
vision.py            → Скриншоты и вырезание области
cell_recognizer.py   → Распознавание клеток (OpenCV)
board.py             → Структура данных игрового поля
solver.py            → Логика принятия решений
solver_brain.py      → Дополнительные эвристики
clicker.py           → Управление мышью
safety.py            → Система безопасности
hotkeys.py           → Горячие клавиши
selector.py          → Выбор области игры
config.py            → Настройки
```

## Правила решателя

1. **Нулевая клетка** — все закрытые соседи безопасны
2. **Все мины найдены** — если число = кол-во закрытых соседей, все они мины
3. **Флаги расставлены** — если число = кол-во флагов, остальные соседи безопасны
4. **Вероятности** — если нет гарантированного хода, выбирается клетка с минимальным риском

## Настройки (config.py)

```python
BOARD_AREA = None     # Координаты области (автоопределение при None)
CELL_SIZE = 30        # Размер клетки в пикселях
STOP_ON_MINE = True   # Остановка при взрыве
MOVE_DELAY = 0.3      # Задержка между ходами (сек)
```
