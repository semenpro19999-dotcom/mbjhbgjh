# Что было исправлено в Minesweeper AI

## Критические баги (краши)

### ❌ Баг 1: BOARD_AREA = None
**Файл:** `config.py`, `vision.py`  
**Проблема:** `capture_board()` пыталась распаковать `None` в координаты → крах  
**Решение:** 
- Добавлена проверка `if self.board_area is None: return None`
- При запуске автоматически вызывается `selector.select_area()` для выбора области

### ❌ Баг 2: Clicker не имел метода click()
**Файл:** `clicker.py`  
**Проблема:** `AIController` вызывал `clicker.click(x, y)`, но метод отсутствовал  
**Решение:** Добавлен метод `click(x, y, button='left')` который переводит координаты клетки в пиксели экрана

### ❌ Баг 3: Solver не имел метода get_next_move()
**Файл:** `solver.py`  
**Проблема:** `AIController` вызывал `solver.get_next_move()`, но метод отсутствовал  
**Решение:** Добавлен метод который возвращает `('open', x, y)` или `('flag', x, y)`

## Логические ошибки

### ❌ Баг 4: Solver искал мины вместо безопасных клеток
**Файл:** `solver.py`, метод `find_safe_moves()`  
**Проблема:** Код искал клетки со значением `'*'` рядом с нулём — это мины, а не безопасные!  
**Решение:** Переписана логика:
```python
# Было (НЕПРАВИЛЬНО):
if self.board.grid[ny][nx] == '*':
    safe_moves.append((nx, ny))

# Стало (ПРАВИЛЬНО):
for nx, ny in self.board.get_closed_neighbors(x, y):
    safe.add((nx, ny))
```

### ❌ Баг 5: Бот делал один ход и останавливался
**Файл:** `ai_controller.py`  
**Проблема:** Цикл `while` содержал `break` после каждой итерации  
**Решение:** Заменено на `continue` + `time.sleep(config.MOVE_DELAY)`, теперь бот работает непрерывно

## Интеграция модулей

### ❌ Баг 6: Модули не работали вместе
**Файл:** `ai_controller.py`  
**Проблема:** `AIController` не использовал `CellRecognizer` и `Board`, передавал сырой скриншот в Solver  
**Решение:** Полный цикл теперь работает:
1. `Vision.capture_board()` → изображение
2. `CellRecognizer.analyze_board()` → матрица
3. `Board(grid=matrix)` → объект поля
4. `Solver.get_next_move()` → ход
5. `Clicker.click()` → клик мышкой

## Новые возможности

### ✅ Вероятностный анализ
**Файл:** `solver.py`, метод `_estimate_mine_probability()`  
- Когда нет гарантированных ходов, бот рассчитывает риск для каждой закрытой клетки
- Выбирает клетку с минимальной вероятностью мины

### ✅ Обнаружение взрыва
**Файл:** `vision.py`, метод `detect_explosion()`  
- Анализирует красные пиксели на поле
- При обнаружении >5% красных → останавливает бота

### ✅ Флагание мин
**Файл:** `solver.py`, `ai_controller.py`  
- Solver возвращает `('flag', x, y)` для гарантированных мин
- Clicker делает правый клик

### ✅ Горячие клавиши
**Файл:** `hotkeys.py`

- Запускается в отдельном потоке

### ✅ Улучшенный selector
**Файл:** `selector.py`  
- Визуальный выбор области с превью
- Рисует точки и прямоугольник
